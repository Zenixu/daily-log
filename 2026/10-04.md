## 📚 Yang dipelajari hari ini
- **Debug script bash cron pengingat streak.** Ternyata ada 2 bug sekaligus:
  1. **Path salah** — script nunjuk ke `/home/zennrch/Projects/daily-log`, padahal repo-nya di `/home/zennrch/Projects/GITHUB/daily-log`. Akibatnya tiap hari cuma keluar "repo tidak ditemukan".
  2. **Logika salah** — script cuma cek commit di repo `daily-log` saja. Padahal **streak GitHub dihitung dari commit di repo MANA PUN**. Jadi script bisa bilang "belum commit!" padahal kotak hari itu sudah hijau dari repo lain.
- **Cara baca kalender kontribusi GitHub tanpa API/token.** Halaman `github.com/users/<user>/contributions` itu HTML biasa, dan tiap hari punya atribut `data-date="YYYY-MM-DD"` + `data-level="0-4"`. Cukup `curl` + `grep -o`, nggak perlu OAuth atau GraphQL.
- **Pelajaran desain: pakai sumber kebenaran yang benar.** Sumber kebenaran streak itu kalender GitHub (yang user lihat), bukan commit lokal. Commit lokal dipakai cuma sebagai cadangan kalau GitHub nggak terjangkau.
- **`set -e` itu berbahaya di script yang banyak `grep`.** `grep` mengembalikan exit 1 kalau nggak nemu apa-apa, dan dengan `-e` script langsung mati di situ. Ganti jadi `set -uo pipefail` (tanpa `-e`).
- **Portabilitas aritmetika tanggal di bash.** GNU `date -d 'yesterday'` vs BSD `date -v-1d` beda; cara aman pakai `|| ` buat nyediain dua-duanya.

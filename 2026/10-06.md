- **Sensor kompas itu berisik dan penuh jebakan.** Tiga bug nyata yang ketemu:
  1. Android mengirim **dua jenis event**: `deviceorientationabsolute` (absolut, dipercaya) dan `deviceorientation` (relatif). Kalau dua-duanya dipakai, nilai relatif **menimpa** absolut → jarum kompas loncat-loncat. Solusi: begitu absolut pernah datang, buang sampel relatif dalam jendela waktu tertentu.
  2. **Rata-rata linear itu SALAH untuk sudut.** `(350 + 10) / 2 = 180` — padahal arah tengah antara 350° dan 10° itu **0°**. Harus pakai **rata-rata sirkular** (geser lewat selisih sudut terpendek).
  3. **Lompatan 360°↔0°.** 350°→10° harus terbaca **+20°**, bukan −340°.
- **Tidak semua izin Android bisa lewat popup.** Mode Jangan Ganggu butuh izin **"Akses Jangan Ganggu"** yang TIDAK bisa diminta lewat dialog — user harus mengaktifkannya manual di Pengaturan sistem. Jadi UI wajib menyediakan tombol pintasan ke Settings, bukan cuma `requestPermission()`.
- **Bridge plugin Capacitor** (`registerPlugin`) + desain **aman di web**: semua fungsi native mengembalikan nilai default / no-op kalau dijalankan di browser, jadi satu UI yang sama jalan di web maupun Android tanpa percabangan berantakan.
- **Pisahkan logika murni dari efek samping** supaya bisa di-unit-test: `shouldEnableDnd()`, `smoothHeading()`, `shortestAngleDelta()`, `acceptHeadingSample()` — semuanya fungsi murni tanpa sentuhan DOM/native, jadi bisa diuji tanpa HP.

## 💡 Snippet / temuan menarik
```js
// Rata-rata bergerak SIRKULAR — bukan linear. Ini kuncinya.
export function smoothHeading(prev, next, alpha = 0.2) {
  const n = normalizeHeading(next);
  if (n == null) return prev;
  const p = normalizeHeading(prev);
  if (p == null) return n;
  const a = Math.max(0, Math.min(1, alpha));
  const d = shortestAngleDelta(p, n);   // (-180, 180]
  return normalizeHeading(p + a * d);
}
```

```js
// Selisih sudut TERPENDEK: 350° → 10° = +20° (bukan −340°)
export function shortestAngleDelta(from, to) {
  let d = (to - from) % 360;
  if (d > 180) d -= 360;
  if (d <= -180) d += 360;
  return d;
}
```

```js
// Cegah nilai RELATIF menimpa ABSOLUT → akar bug kompas "loncat"
export function acceptHeadingSample({ absolute, gotAbsolute, lastAbsoluteAt, now, windowMs = 1000 }) {
  if (absolute) return true;
  if (gotAbsolute && now - lastAbsoluteAt < windowMs) return false;
  return true;
}
```

## 🧱 Kesulitan / yang masih bingung
- **Urutan izin iOS vs Android beda.** iOS butuh `DeviceOrientationEvent.requestPermission()` yang harus dipanggil dari gesture user; Android langsung jalan. Satu jalur kode harus menangani dua perilaku ini.
- **Debug sensor tanpa perangkat itu mustahil.** Di desktop/headless tidak ada event sensor sama sekali — jadi wajib diuji di HP asli. Fungsi murni + unit test jadi penyelamat karena bagian logika tetap bisa diverifikasi tanpa HP.
- **Trade-off smoothing**: `alpha` kecil = lebih halus tapi lambat merespons; terlalu kecil malah terasa "lengket" dan tidak natural.

## Format

Tiap file project pakai struktur:

```markdown
# Nama Project

**Repo:** link
**Stack:** ...
**Status:** ...

## 🎯 Goal
## ✅ Done
## 🚧 In Progress
## 📝 Log
```

Tambah log baru di bagian `📝 Log` setiap kali ada progress. Ini yang bikin commit nyata tiap hari.
